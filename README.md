# Homebrew tap

```bash
brew install --cask gollasandeepkumar/tap/avatar-reminder
```

[Avatar Reminder App](https://gollasandeepkumar.github.io/AvatarReminder-releases/): an animated character walks onto your Mac's screen and reminds you to drink water, stretch and rest your eyes. It updates itself after installing.

The app isn't notarized by Apple yet: the first time you open it, go to System Settings → Privacy & Security and click **Open Anyway**.
